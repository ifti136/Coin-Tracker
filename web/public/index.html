v4.0.5 Latest — 2026

Full-width desktop layout and documentation architecture

  • Resolved desktop viewport gap: main container now fills the entire available width with clean padding
  • Extracted detailed release histories into standalone platform changelogs
v4.0.4 — 2026

Web progress card generator and share flow

  • Generated 900×500 branded progress card mirroring Android progress card graphics
  • Shows balance, goal, progress bar with milestone ticks, earnings stats, and 7-day rate
  • Native Web Share API integration on supported devices with automatic PNG download fallback
v4.0.3 — 2026

Chart-to-History navigation and accessible data tables

  • Click any chart data point or doughnut segment to see a selection bar with a "View matching transactions" button
  • Timeline click pre-fills the History date range for that day; doughnut click pre-fills the source/category filter
  • Selection bar includes a dismiss action and is announced to assistive technology via ARIA region
v4.0.2 — 2026

Keyboard navigation and shortcut guide

  • Added global navigation shortcuts (G then D, A, H, N, S)
  • Added slash (/) shortcut to quickly jump to and focus History search
  • Added interactive shortcut help modal toggled via ? or top bar icon
v4.0.1 — 2026

Transaction undo capability

  • Added undo toast action for Add Coins, Spend Coins, and Quick Actions
  • Reverting a transaction safely removes the record and recalculates running balances
  • Screen-reader accessible undo action with explicit aria-label and 8s window
v4.0.0 — 2026

Gold and graphite web overhaul

  • New gold and graphite design tokens, typography roles, and shared primitives
  • Rebuilt dashboard with a focal balance and goal panel, milestone markers, and clearer entry hierarchy
  • Restructured analytics, history, notifications, settings, login, and admin surfaces
  • Improved keyboard focus, reduced-motion handling, and chart text summaries
  • Versioned stylesheet and offline asset coverage for the new visual system
v3.3.0 — 2026

Web and mobile feature parity

  • Added six achievements mirroring mobile, including Master Hoarder, First Payday, and streak milestones
  • Added Income and Expense pill badges to transaction history
  • Context-aware empty states with a Clear Filters action
  • Dashboard remaining-goal pill and 25%, 50%, 75% milestone ticks
  • Separated the Danger Zone for high-impact destructive operations
  • Live database sync status indicator and full-screen loading states
  • Added a New Action tile in the Quick Actions grid
v3.2.0 — 2026

Safety cache system and offline sync

  • Local safety snapshots saved after successful database queries
  • Automatic cache restore if the database is empty, plus offline conflict resolution
  • Offline safety banner with cached mode operations
v3.1.2 — 2026

Notification badge tracking and pill pagination

  • Persistent unread achievement badge clearing and a Read All action
  • Sliding-window pill pagination with rounded buttons and ellipsis
v3.1.1 — 2026

Notifications hub and layout improvements

  • Dedicated notifications page with activity alerts and achievements
  • Top bar bell badge showing the unread notification counter
  • Separated swipe and edit actions in history
v3.1.0 — 2026

Bug fixes and stability

  • Resolved build and compile issues across web and mobile targets
v3.0.0 — 2026

Analytics intelligence and Android widget

  • 7-day rolling average and estimated days to goal
  • Best Earning Week and 7-day earning rate in Analytics
  • Glance-based Android home screen widget with balance and progress
  • Milestone notifications and progress card sharing generator
v2.1.0 — 2026

Firebase direct auth

  • Direct Firebase Auth integration via synthetic email accounts

  • Target SDK 35, Compose BOM 2025.05.01, and KSP build tooling
